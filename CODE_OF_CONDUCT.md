# Code of conduct

This project uses a normal standard for open-source discussion. It applies to issues, pull requests, and other spaces maintained for this repository. It does not add conditions to the MIT license, and it does not police how a course uses the program.

## Expected behavior

- Be respectful and specific.
- Assume good faith, and accept correction.
- Keep criticism on the work.
- Give credit when you use someone else's idea.

## Unacceptable behavior

- Harassment, insults, or sexualized comments.
- Personal attacks, or publishing someone's private information without permission.
- Trolling or repeated bad-faith disruption.

## Coursework

Do not post real student work, a corpus database, or other private course files in issues or pull requests. Use a short synthetic example instead.

## Reporting

Open a GitHub issue, or contact the repository maintainers through the address they publish on the repository, if one is listed. Describe what happened, where, and whether it is ongoing. Maintainers will look at the report and may warn, edit, or block someone who keeps breaking these expectations. They will say what they decided if it is safe to do so.

This document is a project policy for collaboration. It is not a field-of-use limit on the software.
